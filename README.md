
# Keva Health | Healthcare Analytics & Statistical Modeling

## Project Overview

Analyzed nine years of California asthma-related emergency department visits and EPA air quality data (2011–2019) to investigate relationships between air pollution and healthcare utilization.

## Methodology

- Integrated public healthcare and environmental datasets.
- Conducted exploratory data analysis (EDA).
- Developed six linear regression analyses using R.
- Examined AQI, ozone, and PM2.5 associations with asthma-related ER visits.
- Visualized analytical findings using Tableau.

## Key Findings

Identified statistically significant positive associations between poor air quality indicators and asthma-related emergency department visits.

Proposed using these findings to inform AQI-based patient alerts and asthma risk awareness within Keva Health's application.
